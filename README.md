# Family360 — דמו מלא

[פתיחת הדמו בדפדפן](https://huxhkuh.github.io/family360-demo/)

הדמו כולל חמש חלופות עיצוב, כניסה כלקוח, נציג, בעל מקצוע ומנהל, שאלון מלא, מסמכים, פגישות ומשימות המשך.

כל הנתונים בדויים. אין חיבור למערכת הפעילה, למסד נתונים או לספק תשלום. שינויים במהלך ההדגמה נשמרים בזיכרון הלשונית בלבד ונמחקים ברענון. אין להזין מידע אישי אמיתי.

## פרסום ועדכון

GitHub Pages מפרסם את `index.html` מענף `main`. כדי לעדכן, יש להחליף את הקובץ בתוצר הדמו המלא שנבדק ולדחוף את העדכון לענף זה. אין להעלות קוד שרת, הגדרות שירותים או קובצי סביבה לריפו זה.

קובץ HTML עצמאי עם קוד, סגנונות ופונטים מוטמעים; אין התקנות או תהליך בנייה בשרת. הודעת רישיון הפונט כלולה בקובץ.
